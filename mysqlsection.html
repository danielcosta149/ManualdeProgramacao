MySQL

Olá, seja bem vindo à seção MySQL. Neste espaço você encontrará informações e dicas sobre como utilizar o MySQL e suas extensões para criação de banco de dados, linkagem com PHP e muito mais.

Instalação:

Antes de começar a criar tabelas, entidades e atributos, é necessário realizar o processo de instalação. Logo abaixo, estará listado o passo a passo da instalação do MySQL no Windows:

  1. Acesse o site oficial do MySQL: dev.mysql.com/downloads/installer/
  2. Baixe o instalador recomendado para Windows (MySQL Installer).
  3. Configure o MySQL.
  4. Finalize a instalação e aguarde a configuração dos serviços.
  5. Após a instalação, você pode acessar o MySQL Workbench para gerenciar bancos de dados de forma gráfica.

Para verificar se o MySQL foi instalado corretamente, abra o prompt de comando e digite:
mysql --version

Criação de um Banco de Dados

Agora veremos como utilizar o MySQL Workbench, em específico, a criação de um Banco de Dados do zero. Posteriormente veremos os comandos e códigos para facilitar a criação desses banco de dados através do Query (a caixa de comandos do MySQL), por agora iremos apenas interagir com os botões interativos do próprio MySQL. Segue abaixo o passo a passo para realizar isso.

  1. Abrindo o MySQL Workbench 8.0, veremos esta tela:
  2. Clicando no Local instance (que já vem de fábrica após a instalação), seremos levados para outra guia do MySQL onde iremos trabalhar com bancos de dados, lá temos "Schemas" já vindos de fábrica e poderemos criar nossos próprios Schemas também ou Banco de Dados como preferir. (Obs: Quando você clicar pela primeira vez no Local instance, ele vai pedir aquela senha que você criou, mas é só na primeira vez, depois ele não pergunta mais.)
  3. Próximo passo é, clicar no "Create a new schema in the connected server", um botão localizado na parte superior da tela, para a criação de um novo Schema/BD.
  4. Clicando nele, uma nova guia será aberta para a criação desse schema, nessa parte você colocará o nome do seu banco de dados e outros configurações como o Charset (que por convenção deixaremos no 'utf8'). Feito isto, clique em "Apply".
  5. Uma nova tela será aberta, por agora, clicaremos em "Apply" mesmo pra continuar; E "Finish" para criar o Schema.
